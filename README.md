# A-Aleksanyan.github.io

Personal academic website of Arusyak Aleksanyan, PhD: academic and professional profile, research and composite indices, teaching, publications, and contact details. Published with GitHub Pages at <https://a-aleksanyan.github.io/>.

## Files

| Path | Content |
|---|---|
| `index.html` | English page (main site) |
| `hy/index.html` | Armenian page |
| `style.css` | Design for both pages (colours are set at the top of the file) |
| `script.js` | Menu, publication filters, copy-email button and other small features |
| `files/Arusyak_Aleksanyan_CV.pdf` | Downloadable CV (contains no private contact details) |
| `images/` | Portrait, presentation photo, browser-tab icon and the preview image used when the link is shared |

## Common updates

- **Add a publication:** copy one `<li class="pub-card" …>` block in `index.html` and edit it. Set `data-type` to `article`, `book`, `chapter`, `paper` or `dataset` so the filter buttons work. Put your own name in `<strong>…</strong>`.
- **Replace the CV:** upload a new PDF with the same name, `files/Arusyak_Aleksanyan_CV.pdf`.
- **Change a photo:** replace the file in `images/` and keep the same file name.
- When you change content in English, make the matching change in `hy/index.html`.
